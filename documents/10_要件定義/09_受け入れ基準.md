# 09 受け入れ基準

Phase1は、以下をすべて満たしたときに要件を満たすものとする。

- [ ] ユーザーがブラウザ上で録音を開始・停止できる。
- [ ] 最大5分の日本語音声を録音対象として扱える。
- [ ] 録音停止後、確認画面なしでAI文字起こしとAI構成評価に進む。
- [ ] AIが文字起こし結果をもとに、PREPを重視した話の構成評価を返す。
- [ ] 評価結果として、総合点・PREP観点の評価・良い点・改善点・具体的な改善提案が表示される。
- [ ] ユーザー登録・ログイン・履歴保存なしで利用できる。
- [ ] 音声・文字起こし・評価結果を保存しない。
- [ ] 文字起こしや評価に失敗した場合、ユーザーが再録音できる。
- [ ] マイク利用が許可されていない場合、録音を開始できない理由が表示される。
