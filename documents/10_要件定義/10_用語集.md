# 10 用語集

本要件定義書で用いる用語を定義する。

| 用語 | 定義 |
| --- | --- |
| Voice Insight | 本アプリケーションの名称。ブラウザ上で話した内容をAIで分析し、話し方の改善につなげる音声分析アプリ。 |
| Phase1 | 話した内容の「構成」をPREP観点で評価する初期リリース範囲。音声特徴の分析は含まない。 |
| Phase2以降 | 息継ぎ・声の速さ・声のトーンなど、音声特徴に基づく分析を追加する将来範囲。 |
| 文字起こし（STT） | 録音した音声をテキストに変換する処理。Speech to Text。Phase1では日本語のみ対象。 |
| 構成評価 | 文字起こし結果をもとに、話の構成（伝わりやすさ）を評価する処理。 |
| PREP | Point（主張）→ Reason（理由）→ Example（具体例）→ Point（結論）の順で話を構成する型。Phase1の評価で重視する。 |
| 総合点 | 話の構成の分かりやすさを表す指標として表示する点数。 |
| 改善提案 | 次回話す際にそのまま意識できる、具体的な表現で示すフィードバック。 |
| 無音区間 | 発話中の音声が途切れている区間。Phase2以降の息継ぎ分析で扱う。 |
