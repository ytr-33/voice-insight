# Voice Insight — Phase1 デモ（画面イメージ確認用モック）

お客様に「どんなサイトになるか」のイメージを掴んでいただくための、画面イメージのモックです。
**実際の録音・AI文字起こし・構成評価は動作しません。** ダミーデータで画面と流れだけを再現しています。

## 開き方

`demo/index.html` をブラウザでダブルクリックして開くだけです（ビルド・サーバー不要）。

```bash
open demo/index.html      # macOS
```

## 収録している画面（要件定義との対応）

| デモ画面 | 内容 | 要件ID |
| --- | --- | --- |
| 録音 | マイクボタン／プライバシー注記 | S-01, F-01, NF-04 |
| 録音中 | 経過時間・波形・停止ボタン | S-01 |
| マイク不許可 | 利用できない理由と再試行導線 | S-01, NF-06 |
| 処理中 | 文字起こし→評価のステップ表示 | S-02, F-02/F-03 |
| 評価結果 | 総合点／PREP観点／良い点／改善点／改善提案 | S-03, F-04, 04_評価要件 |
| エラー | 失敗時の再録音導線 | S-04, NF-06 |

画面下部の「デモ画面」ツールバーから、各画面を直接表示して確認できます。
録音画面のマイクボタン →（停止）→ 処理中 → 評価結果、という本来の流れも擬似的にたどれます。

## 注意（このデモはあくまで叩き台）

- 配色・レイアウト・コピー・点数スケール（100点満点表示など）は**仮**です。
  要件定義書では、評価プロンプト・出力フォーマット・点数の算出基準・技術スタックは
  後続の設計工程に委ねられています（`07_システム・技術要件.md` 7.3 / `04_評価要件.md` 4.4）。
- 評価結果のサンプル文言はイメージ用のダミーです。
