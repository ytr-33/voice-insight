# レビューフェーズ

完成した基本設計書ドラフトを品質基準に照らして採点する。

## 手順

1. `references/quality-checklist.md` を読む。
2. 基本設計書の全ファイルを読む。
3. 要件定義書も参照し、要件IDとの対応と矛盾を確認する。
4. 複数ファイルの場合は、設計ID、参照、用語、状態名、集約ファイルの整合を確認する。
5. `quality-checklist.md` の出力フォーマットで重大度付き指摘を返す。

## 厳守

- ドラフトを書き換えない。
- 要件違反、未対応要件、捏造された判断、データ保存方針の矛盾を優先して拾う。
- 致命が1件でもあれば不合格にする。
