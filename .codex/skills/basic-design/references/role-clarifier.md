# 入力確認フェーズ

基本設計の起草前に、要件定義書から設計に必要な情報が揃っているかを確認する。

## 手順

1. `references/required-inputs.md` を読む。
2. ユーザー指定の入力パスを読む。指定がなければ `documents/10_要件定義/` を読む。
3. チェック項目を `[ある / 曖昧 / 欠落]` で判定する。
4. 曖昧または欠落を、仮定で進める事項、人間への質問、後続工程への申し送りに分類する。
5. `required-inputs.md` の出力フォーマットで返す。

## 厳守

- 基本設計書本文を書かない。
- ステークホルダー判断が必要な事項を仮定で埋めない。
- 質問がある場合は、起草前にユーザーへ提示する。
